01

WHAT THIS TOOL DOES

This scanner is a high-performance multithreaded network reconnaissance instrument engineered for security operators, penetration testers, and network engineers.

Given any target hostname or IPv4 address, the engine systematically assesses designated TCP port ranges to verify active listening services, extracts raw banner greetings and HTTP headers to fingerprint running software versions (e.g. OpenSSH, Apache, Nginx), and generates formal pentest reports in PDF, CSV, and JSON formats.

MISSION: Provide instant graphical visibility without sacrificing the raw diagnostic power and learning curve of terminal-based reconnaissance tools.
02

HOW IT WORKS · THE 65,535 DOORS ANALOGY

Think of a networked server as a vast fortress containing exactly 65,535 TCP doors. Behind closed doors, nothing responds. Behind open doors, specific daemon processes (SSH, web servers, databases) stand ready to communicate.

A port scanner is an operator walking down the corridors testing the door knobs. In technical terms, it requests the operating system kernel to perform a standard TCP 3-way handshake (SYN → SYN-ACK → ACK) via the non-blocking connect_ex() socket system call.

  • Return Code 0 (Door Opens): A service is listening and the TCP connection succeeds.
  • Connection Refused (Locked Door): The target host actively returns an RST packet indicating no listener.
  • Timeout (Filtered / Firewall): An intermediate firewall or packet filter drops the probe silently.

Once a door opens, our scanner immediately probes the connection: it reads the server's initial greeting banner or dispatches a lightweight HEAD / HTTP/1.0 probe to discover the exact software name and version.

FEATURES & NMAP COMPATIBILITY

  • Concurrent Socket Engine: Scalable concurrency driven by Python's ThreadPoolExecutor, capable of surveying hundreds of ports per second without overwhelming local resources.
  • Dynamic Banner Fingerprinting: Captures software release strings, protocols, and OS hints on open ports (the analogue to Nmap's -sV flag).
  • Unified Core Architecture: "One brain, two faces" — the same scan() engine powers both the interactive web dashboard and the headless command-line interface.
  • Live Nmap Command Generator: Every click on presets, service chips, or banner options dynamically constructs the exact equivalent nmap command syntax in real time.
  • Server-Sent Events (SSE) Streaming: Low-latency push channel delivers live port discoveries and console logs to the browser instantly as sockets complete.
  • Pentest-Grade PDF Reports: Generates executive-ready security audit reports with formal monospace tables, metric summaries, and authorized testing disclaimers.

LEGAL NOTE & SAFETY GUARDRAILS

⚠️ MANDATORY NOTICE: SCAN ONLY SYSTEMS YOU OWN OR HAVE PERMISSION TO TEST.

Port scanning unauthorized systems may be interpreted as reconnaissance for an intrusion and can violate computer security statutes (such as the Computer Fraud and Abuse Act in the US, the Computer Misuse Act in the UK, and international equivalents).

To enforce safe practices, this tool embeds strict guardrails:

  • Explicit Consent Requirement: Scans cannot be dispatched without confirming testing authorization.
  • Concurrency Capping: Worker threads are strictly capped at 200 to prevent denial-of-service on scanned hosts or exhaustion of local socket descriptors.
  • Public Scope Limitations: Full 1–65535 surveys are restricted to loopback (127.0.0.1), RFC1918 private subnets, or Nmap's officially authorized public testing host (scanme.nmap.org).
